# AxiomAtlas — Calculator Suite

Live website: https://axiomatlas.netlify.app/

AxiomAtlas is a standalone calculator website covering math, algebra, geometry, graphing, physics, statistics and finance. This repository is being populated from the existing deployment. `site/` is the Netlify publish directory; the source build package is archived separately.
