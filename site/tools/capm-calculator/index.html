How CAPM (Capital Asset Pricing Model) Calculator Works

1 Overview

Calculate expected asset return E[R_i] = R_f + β(E[R_m] − R_f), equity risk premium, and Jensen’s Alpha. Designed for finance (portfolio analysis), this tool evaluates your inputs in canonical SI or domain units and generates a verified step-by-step derivation.

2 Formula

E[R_i] = R_f + β_i (E[R_m] − R_f); α = R_actual − E[R_i]

3 Variables & Constants

SymbolMeaningUnit
rfRisk-free rate R_f%
rmExpected market return E[R_m]%
betaAsset Beta βDimensionless
actualActual portfolio return (optional for Alpha)%
OutputCAPM expected return E[R_i]%
OutputMarket risk premium (E[R_m] − R_f)%

4 How It Works

  1. Enter input parameters: Provide values for Risk-free rate R_f (rf), Expected market return E[R_m] (rm), Asset Beta β (beta), Actual portfolio return (optional for Alpha) (actual). If you select an alternative unit from any dropdown, the calculator converts it to the canonical base unit automatically.
  2. Apply governing relation: The solver substitutes the normalized values into E[R_i] = R_f + β_i (E[R_m] − R_f); α = R_actual − E[R_i] using IEEE-754 double-precision arithmetic.
  3. Inspect step-by-step derivation: Review the primary and secondary results on the right, and click Explain Calculation to view the substituted formula and intermediate steps.
