How Thin Lens Equation Calculator Works

1 Overview

Find image distance d_i, linear magnification m, and optical power in Diopters for a thin lens. Designed for physics & engineering (optics), this tool evaluates your inputs in canonical SI or domain units and generates a verified step-by-step derivation.

2 Formula

1/f = 1/d_o + 1/d_i; m = −d_i / d_o

4 How It Works

  1. Enter input parameters: Provide values for Focal length f (f), Object distance d_o (o). If you select an alternative unit from any dropdown, the calculator converts it to the canonical base unit automatically.
  2. Apply governing relation: The solver substitutes the normalized values into 1/f = 1/d_o + 1/d_i; m = −d_i / d_o using IEEE-754 double-precision arithmetic.
