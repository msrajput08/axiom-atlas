How Square Pyramid Calculator Works

1 Overview

Find volume and total surface area of a square pyramid. Designed for geometry & trigonometry (3d geometry), this tool evaluates your inputs in canonical SI or domain units and generates a verified step-by-step derivation.

2 Formula

V=s²h/3; A=s²+2sl

3 Variables & Constants

SymbolMeaningUnit
sBase side sm
hVertical height hm
OutputVolumem³
OutputSurface aream²

4 How It Works

  1. Enter input parameters: Provide values for Base side s (s), Vertical height h (h). If you select an alternative unit from any dropdown, the calculator converts it to the canonical base unit automatically.
  2. Apply governing relation: The solver substitutes the normalized values into V=s²h/3; A=s²+2sl using IEEE-754 double-precision arithmetic.
  3. Inspect step-by-step derivation: Review the primary and secondary results on the right, and click Explain Calculation to view the substituted formula and intermediate steps.
5 Worked Example & Reference Case

6 Assumptions & Limitations

  • All dimensions must be positive; Torus requires Major Radius R > Tube Radius r.
  • Evaluated in IEEE-754 double-precision floating-point arithmetic (~15–17 significant decimal digits) with explicit domain boundary checks.
